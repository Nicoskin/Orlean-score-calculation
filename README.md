# Счётный лист Орлеана

Одностраничный сайт для подсчёта победных очков в настольной игре «Орлеан» — вместо карандаша и листочка.

- подсчёт по категориям: сначала товары у всех игроков, потом монеты, потом город;
- табло в стиле игрового поля: жетоны товаров, тайлы производств и вымпелы очков — картинки из правил;
- подсказки «Как считать» с примерами из правил;
- монеты набираются с клавиатуры — широкое поле вместо тыканья в «плюс» полсотни раз;
- фактории и жетоны горожан умножаются на уровень развития;
- при ничьей сайт сам разбирает её по уровню развития, а если уровень тоже равный — спрашивает, чей маркер дальше по шкале (можно ответить «поровну» — тогда победителей несколько);
- до 4 игроков;
- выгрузка результатов: текст (копируется одной кнопкой), картинка PNG или JSON.

Сайт — это один файл `index.html` без сборки и зависимостей (шрифты подгружаются с Google Fonts, картинки лежат в `img/`).

## Как выглядит текст итогов

```
Игрок 1
Парча 10
Вино 6
Зерно 1
Монеты 52
5+2*5 35
104

Игрок 2
Шерсть 4
Вино 6
Сыр 6
Зерно 1
Монеты 43
4+3*5 35
95
```

Числа рядом с товарами — это уже победные очки. Галочка «Показывать количество» переключает строки в вид `Парча 2×5 10`.
Строка `5+2*5 35` — это фактории + жетоны горожан, умноженные на уровень развития.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий, например `orleans-score`.
2. Отправьте код:
   ```bash
   git init -b main && git add . && git commit -m "Счётный лист Орлеана"
   ```
   ```bash
   git remote add origin https://github.com/<ваш-логин>/orleans-score.git && git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/orleans-score/`.

## Что и где сохраняется

| Что | Где | Сколько хранится |
|---|---|---|
| Имена и цвета игроков | куки `orleans_players` | 400 дней, срок продлевается при каждом заходе |
| Очки текущей партии | `localStorage` браузера | пока не нажата «Новая партия» |

Данные никуда не отправляются и живут только в браузере конкретного устройства.

**iPhone / Safari:** Safari стирает куки и `localStorage`, записанные сайтом, если на сайт не заходили 7 дней. Чтобы настройки жили дольше, откройте сайт в Safari → «Поделиться» → **«На экран „Домой“»** и запускайте его оттуда — для такого ярлыка ограничение не действует.

## Локальный запуск

Откройте `index.html` в браузере. Работать будет всё, кроме выгрузки картинки: браузер запрещает холсту читать локальные файлы, поэтому PNG рисуется только по `http(s)`. Чтобы проверить и картинку, поднимите любой локальный сервер:

```bash
python -m http.server 8000
```

## Правила подсчёта

Победные очки в конце 18-го раунда (перед подсчётом жетон горожанина из верхнего левого угла поля получает тот, кто построил больше всех факторий; при ничьей — никто):

| За что | Очки |
|---|---|
| Парча | 5 за жетон |
| Шерсть | 4 за жетон |
| Вино | 3 за жетон |
| Сыр | 2 за жетон |
| Зерно | 1 за жетон |
| Монеты | 1 за монету |
| Фактории и жетоны горожан | (фактории + горожане) × уровень развития |

При равенстве очков побеждает тот, кто продвинулся дальше по шкале развития; если и там ничья — победителей несколько.

Более высокий уровень развития — это заведомо более дальнее деление шкалы, такую ничью сайт разрешает сам. А кто дальше внутри одного уровня, по планшетам не видно — про это сайт спросит в блоке «Итоги партии». Ответ запоминается для конкретной пары игроков и сбрасывается, если очки изменились.

## Картинки

Иллюстрации в `img/` вырезаны из русских правил «Орлеана» (GaGa Games) и принадлежат правообладателям игры. Скрипт, которым они вырезаны, — `tools/extract.py` (нужны `pymupdf`, `Pillow`, `numpy` и файл правил).
